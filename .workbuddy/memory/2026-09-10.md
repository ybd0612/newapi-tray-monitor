## 主窗体变宽根因排查
- 只读审查了 `src/shared/tauriApi.js`、`src/dashboard/App.jsx`、`src-tauri/tauri.conf.json`、Tauri Window API 与相关历史提交。
- 发现窗口状态链路存在单位不一致：Tauri `onResized` / `outerSize()` 返回物理像素，状态写入 `panelSize`；恢复时 `getPanelPosition()` 固定用 `PhysicalSize(240,112)`，同时配置初始尺寸是逻辑像素；多屏 DPI/缩放变化时仍按物理像素恢复，可能导致显示尺寸随缩放比例异常。
- 另发现恢复后 `setSize()` 触发 `onResized`，回调又调用 `saveWindowState()`，该函数用 `outerSize()`（含边框，且与 inner size 语义不同）覆盖持久化尺寸；虽当前启动恢复强制固定 240x112，但会持续污染配置并放大单位混用风险。
- 当前未修改源码；结论与修复建议待用户确认后实施。

## 修复完成
- 主窗体固定尺寸改为使用 `LogicalSize(240,112)`，不再保存或恢复 `panelSize`，移除 `onResized` 状态写回，避免 DPI 切换时物理尺寸污染配置。
- 恢复位置时读取可用显示器工作区；若保存位置落在已断开显示器或越界，则回退/裁剪到当前可用显示器。
