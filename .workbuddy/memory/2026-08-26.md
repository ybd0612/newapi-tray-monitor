## 修复：开机自启后主窗口不显示
- 现象：开机自启后程序在托盘运行，但主窗口隐藏，需手动点托盘图标才显示。
- 根因：`tauri.conf.json` 主窗口 `"visible": false`，任何方式启动都隐藏到托盘。
- 方案：`tauri-plugin-autostart`（v2.5.1）Builder 支持 `.args(["--autostart"])`，让注册表 Run 命令带参数；`lib.rs` setup 中检测 `std::env::args()` 含 `--autostart` 时调用 `show_window(app.handle(), "main")`。手动启动不带参数，保持隐藏到托盘。
- 注意：setup 闭包里 app 是 `&mut App`，需用 `app.handle()` 转 `&AppHandle`（E0308 坑）。
- 验证：cargo build 通过；实测带 `--autostart` 启动主窗口可见（Title=NewAPI监控），不带参数启动主窗口隐藏（Title 空）。
- **用户侧生效前提**：已启用过开机自启的机器，注册表项仍是旧命令（无参数），必须到设置页把"开机自动启动"关闭再打开一次，才会写入带 `--autostart` 的新命令。
- 提交：`8e51d5a 修复开机自启后主窗口不显示`（仅推送需用户确认）。
